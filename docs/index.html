Flask-ADB-toolkit

One little flask 🧪 — every flashing tool you'll ever need. A powerful, menu-driven terminal toolkit for Android Debug Bridge, built for people who want to tinker, not memorize commands.

Get Started View Source →

Key Features

Everything you need to manage your Android device, wrapped in a friendly terminal interface.

🚀

Fast & Lightweight

A snappy terminal program that wraps all the scary fastboot and adb commands into friendly numbered options.

📱

Full ADB Control

Flash ROMs, restore stock, flash any partition on any device, deep-clean junk, run performance passes, take screenshots, and install APKs.

🛠️

Easy to Use

Built for people who know nothing about custom ROMs but want to try. No memorizing commands, just plug in and pick from a menu.

Quick Start

Get up and running in under 30 seconds.

bash
# 1. Save the script (paste the contents from the repo) 
nano ~/flask-adb-toolkit.sh
# 2. Make it executable & run 
chmod +x ~/flask-adb-toolkit.sh && ~/flask-adb-toolkit.sh

💡 Windows (Git Bash): Double-click flask-adb-toolkit.bat

💡 Windows (WSL): Follow the Linux steps above inside WSL.
