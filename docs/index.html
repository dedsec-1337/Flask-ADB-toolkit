Flask-ADB-toolkit

One little flask 🧪 — every flashing tool you'll ever need. A powerful, web-based interface for Android Debug Bridge.

Get Started View Source

Key Features

🚀

Fast & Lightweight

Built on Flask, providing a snappy and responsive web interface for all your ADB needs.

📱

Full ADB Control

Manage devices, install APKs, push/pull files, and execute shell commands directly from your browser.

🛠️

Easy to Use

A clean and intuitive UI designed to make Android debugging accessible to everyone.

Quick Start

  1. Clone the repository: 
    git clone https://github.com/dedsec-1337/Flask-ADB-toolkit.git
  2. Navigate to the directory: 
    cd Flask-ADB-toolkit
  3. Install dependencies: 
    pip install -r requirements.txt
  4. Run the application: 
    python app.py
