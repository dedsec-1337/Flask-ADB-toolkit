Key Features

Everything you need to manage your Android device, wrapped in a friendly terminal interface.

🚀

Fast & Lightweight

A snappy terminal program that wraps all the scary fastboot and adb commands into friendly numbered options.

📱

Full ADB Control

Flash ROMs, restore stock, flash any partition, deep-clean junk, run performance passes, take screenshots, and install APKs.

🛠️

Built for people who know nothing about custom ROMs but want to try. No memorizing commands, just plug in and pick from a menu.

Quick Start

Get up and running in under a minute.

1. Install Android Tools

You need adb and fastboot installed on your system.

Ubuntu / Debian 
❯ sudo apt update && sudo apt install android-tools-adb android-tools-fastboot

2. Save the Toolkit Script

Option A: Create the file manually

Run this command to open a new file in the nano editor:

❯ nano ~/flask-adb-toolkit.sh

(Paste the script below, then press Ctrl+O, Enter, and Ctrl+X to save and exit)

Option B: Use the buttons below

flask-adb-toolkit.sh 
Loading script from GitHub...

3. Run the Toolkit

Make the script executable and launch it.

bash 
❯ chmod +x ~/flask-adb-toolkit.sh
❯ ~/flask-adb-toolkit.sh

💡 Windows (Git Bash): Download and double-click flask-adb-toolkit.bat from the repository.

💡 Windows (WSL): Follow the Linux steps above inside WSL.
