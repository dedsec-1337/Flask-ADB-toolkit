Flask-ADB-toolkit

One little flask 🧪 — every flashing tool you'll ever need. Auto-detecting ROM flasher, generic partition tools for any Android device, and a checksum verifier, all in one friendly terminal menu.

Get Started View Source

Key Features

Everything you need to manage your Android device, wrapped in a friendly terminal interface that adapts to whatever mode your phone is in.

Auto-Detecting ROM Flash

Drop a ROM folder anywhere and the flasher finds vbmeta, dtbo, boot, init_boot, vendor_boot, super_empty and the ROM zip — flashes what's there in a safe order, then reboots to recovery and sideloads. Your folder, your layout, no hand-written commands.

Generic Partition Flash

Flash boot, init_boot, recovery, vbmeta, system, super… or type your own partition name — on any Android device, with slot suffix handling and vbmeta verification flags built in.

Checksum Verifier

Paste a file, optionally the expected SHA256, and get a match / no-match verdict before you flash anything. Never flash a corrupted download again.

Recovery & Sideload Helpers

One-tap reboot to recovery from fastboot or booted mode, standalone sideloading for GApps / Magisk zips, and reboot-to-system from recovery when you're done.

Maintenance & Cleanup

A resumable performance pass that speed-compiles every app, deep-clean for orphaned app data, battery & storage reports, live logcat, screenshots, and APK installs.

Cross-Platform

Runs on Linux, macOS, and Windows — via flask-adb-toolkit.bat in Git Bash or WSL. Same real adb/fastboot commands underneath, with YES confirmations before anything dangerous.

Quick Start

Get up and running in under a minute.

1. Install Android Tools

You need adb and fastboot installed on your system.

Ubuntu / Debian
❯ sudo apt update && sudo apt install android-tools-adb android-tools-fastboot

2. Save the Toolkit Script

Option A: Create the file manually

Run this command to open a new file in the nano editor:

bash
❯ nano ~/flask-adb-toolkit.sh

(Paste the script below, then press Ctrl+O, Enter, and Ctrl+X to save and exit)

Option B: Use the buttons below

flask-adb-toolkit.sh
Loading script from GitHub...

3. Run the Toolkit

Make the script executable and launch it.

bash
❯ chmod +x ~/flask-adb-toolkit.sh ❯ ~/flask-adb-toolkit.sh

Windows (Git Bash): Download flask-adb-toolkit.bat from the repository, double-click it, and follow the same menu. 🪟
Windows (WSL): Follow the Linux steps above inside WSL.
