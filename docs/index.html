Key Features

Everything you need to manage your Android device, wrapped in a friendly terminal interface that adapts to whatever mode your phone is in.

Auto-Detecting ROM Flash

Drop a ROM folder anywhere and the flasher finds vbmeta, dtbo, boot, init_boot, vendor_boot, super_empty and the ROM zip — flashes what's there in a safe order, then reboots to recovery and sideloads. Your folder, your layout, no hand-written commands.

Generic Partition Flash

Flash boot, init_boot, recovery, vbmeta, system, super… or type your own partition name — on any Android device, with slot suffix handling and vbmeta verification flags built in.

Checksum Verifier

Paste a file, optionally the expected SHA256, and get a match / no-match verdict before you flash anything. Never flash a corrupted download again.

Recovery & Sideload Helpers

One-tap reboot to recovery from fastboot or booted mode, standalone sideloading for GApps / Magisk zips, and reboot-to-system from recovery when you're done.

Maintenance & Cleanup

A resumable performance pass that speed-compiles every app, deep-clean for orphaned app data, battery & storage reports, live logcat, screenshots, and APK installs.

Cross-Platform

Runs on Linux, macOS, and Windows. On Windows, double-click flask-adb-toolkit.bat — it finds Google's platform-tools next to the script (or on PATH). Same real adb/fastboot commands, with YES confirmations before anything dangerous. Git Bash / WSL optional for the full colour menu.

Quick Start

Get up and running in under a minute.

1. Install Android Tools

You need adb and fastboot installed on your system.

Ubuntu / Debian
❯ sudo apt update && sudo apt install android-tools-adb android-tools-fastboot

2. Save the Toolkit Script

Option A: Create the file manually

Run this command to open a new file in the nano editor:

bash
❯ nano ~/flask-adb-toolkit.sh

(Paste the script below, then press Ctrl+O, Enter, and Ctrl+X to save and exit)

Option B: Download the script

flask-adb-toolkit.sh
Loading script from GitHub...

3. Run the Toolkit

Make the script executable and launch it.

bash
❯ chmod +x ~/flask-adb-toolkit.sh ❯ ~/flask-adb-toolkit.sh

Windows: Download Google's platform-tools and unzip. Put flask-adb-toolkit.bat inside that folder or put the whole platform-tools folder next to the .bat. Double-click the .bat — it finds adb.exe automatically. No need to open the folder and type CMD.
Windows (full colours): Use Git Bash or WSL with the .sh instead.

Uninstall

Removing the toolkit is one file deletion. Removing the dependencies is optional.

1. Remove the toolkit

The toolkit is a single script plus optional per-device progress files (created the first time you run the performance pass). Delete them with:

bash
❯ rm -f ~/flask-adb-toolkit.sh ~/.flask-adb-compile-progress*

Windows: delete flask-adb-toolkit.bat from wherever you saved it.
Screenshots are saved in your Downloads folder (~/Downloads or %USERPROFILE%\Downloads on Windows) — that matches both the .sh and the .bat.

2. Remove adb & fastboot (optional)

If you installed platform-tools just for this toolkit and want the disk space back:

Ubuntu / Debian
❯ sudo apt remove android-tools-adb android-tools-fastboot && sudo apt autoremove

Windows: delete the platform-tools folder you unzipped. If you added it to System PATH, remove that entry under System Properties → Environment Variables → Path (optional — the .bat does not require a global PATH).
Windows (WSL): run the Ubuntu / Debian command inside your distro. To remove the distro entirely: wsl --unregister Ubuntu from PowerShell.
